# Solar Research - Q1 paper track

Goal: a new, publishable (Q1-target) study that clearly extends - not duplicates - Zaher's MSc thesis
on PV-battery sizing for intermittent grids (Baghdad). Ends with a full manuscript draft.

- `ideas/` - idea bank, scoring and selection
- `literature/` - verified references (DOI) and gap analysis
- `method/` - equations and methodology (with references)
- `src/`, `experiments/` - reproducible code and experiment configs
- `results/` - generated tables/figures (never edited by hand)
- `manuscript/` - paper draft
- `reports/` - daily research reports
