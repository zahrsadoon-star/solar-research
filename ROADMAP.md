# Roadmap - Research track

## Stage 1 - Idea selection
- [ ] 1.1 Idea bank: at least 50 distinct research ideas in `ideas/IDEA_BANK.md` (title, research question, method, data needed, expected contribution)
- [ ] 1.2 Score every idea 1-5 on novelty, feasibility with available data, publishability (Q1 fit), effort, overlap risk with the thesis
- [ ] 1.3 Novelty check for the top 10 against recent literature (2021-2026); record closest papers with DOI
- [ ] 1.4 Shortlist 3 with a one-page proposal each -> **Zaher chooses** (stop and ask; do not proceed past this point without his choice)

## Stage 2 - Foundations
- [ ] 2.1 Literature review notes + explicit research gap statement
- [ ] 2.2 Methodology document with every equation, its source and its implementation location
- [ ] 2.3 Target journal shortlist (scope, Q-rank verified at the time, APC, AI-use policy)

## Stage 3 - Implementation and experiments
- [ ] 3.1 Reproducible code (seeds, configs, environment file)
- [ ] 3.2 Validation against thesis baseline / HOMER where applicable
- [ ] 3.3 Main experiments (multiple independent runs, e.g. 30 per algorithm/scenario)
- [ ] 3.4 Statistical tests (Wilcoxon / Friedman + post-hoc), sensitivity and robustness analyses
- [ ] 3.5 Publication-quality figures and tables generated by scripts

## Stage 4 - Manuscript
- [ ] 4.1 Outline following the target journal's guide
- [ ] 4.2 Full draft (Introduction, Literature, Method, Results, Discussion, Conclusion)
- [ ] 4.3 Internal review pass: equations vs code, every number traceable to `results/`, every citation verified
